## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅱ 方法篇 · 第7章 社交媒体数据挖掘**（教材 Tier 2 实验工具）。教材命名："水军检测雷达"。

**学习目标**：理解网络科学的检测思路——水军鉴别不看"说了什么"、而看行为结构是否协同，能用图论指标识别协同发帖网络。

**核心术语**：网络科学（Network Science）、介数中心性（Betweenness Centrality）、协同行为（Coordinated Behavior）、围墙花园（Walled Garden）

**适合对象**：新闻传播专业学生、社交媒体记者、数据新闻进阶学习者

**课前准备**：复习图论基本概念（节点、边、度、中心性）；本工具内置模拟水军关系网，浏览器打开即用、数据不离开本地。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师载入内置水军阵列案例，讲解节点与边的含义（极短发帖时间差的协同节点对相连），先执行一次默认图论清洗，再现场拖动"发帖时间差容忍度"与"异常高出度阈值"两个滑块，演示水军网络如何逐步解体
2. **上手实操**（20 分钟）：学生观察初始力导向图，依次完成四步：记录介数中心性最高的节点并推测其角色（组织者还是关键转发节点）、调大调小两个阈值分别执行"图论清洗"并对比被清洗节点数量、找出会"误伤正常账号"的阈值组合、把最优参数与清洗前后截图整理成一页分析记录
3. **小组讨论**（8 分钟）：社交平台把转发与关注关系数据锁在接口之后（围墙花园），记者拿不到完整关系数据时，用可观测行为推断协同网络的结论有多可靠？
4. **总结**（4 分钟）：水军鉴别的核心是行为协同性——时间上扎堆、结构上异常，而非内容本身。

**课后作业**：选取一个热点话题下 10 个可疑账号的可观测行为，参照本工具的指标框架写一份 300 字协同性判定报告（说明哪些指标可手动验证、哪些受围墙花园限制无法验证）。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%
